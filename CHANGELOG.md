# Changelog

All notable changes are documented in [GitHub Releases](https://github.com/aircwo-systems/tarn/releases).

## Versioning

This project follows [Semantic Versioning](https://semver.org/). During beta (`0.x.y`), minor version bumps may include breaking changes—see each release's notes for migration guidance.

## Release Format

Releases are automatically generated from [conventional commits](https://www.conventionalcommits.org/):

- **Features** (`feat:`) — New functionality
- **Fixes** (`fix:`) — Bug fixes
- **Breaking Changes** — Clearly marked in release notes

## Beta Note

⚠️ Tarn is under active development. Expect API changes and feature refinements as we approach v1.0.
